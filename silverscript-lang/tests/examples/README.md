# SilverScript Examples

This directory contains example contracts used to demonstrate SilverScript and exercise its compiler and runtime.

## Examples, Not Standards

These contracts are just examples, not standards. They may contain errors and are not guaranteed to be secure.

The `FungibleToken` and `FungibleTokenMinter` examples are explained in the [Fungible Token book](../../../docs/fungible-token-book/README.md). For the actual token standard, see [KCC-20](https://github.com/kaspanet/kccs/blob/main/kcc-0020.md).
